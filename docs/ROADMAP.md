# Roadmap

- [x] Phase 1 — local plugin scan, metadata editing, enable/disable, BepInEx 5 installer
- [ ] Phase 2 — read the GitHub registry and render the online browse page
- [ ] Phase 3 — download and install ZIP packages

- [ ] Phase 5 — version and update detection
- [ ] Phase 6 — dependency resolution
